## 开始前
孩子当前学到《Les Loustics 2》第 **___** 单元（家长填写）。
- 已学单元的主题正常出题；未学单元的题打上 `unit` 标签但默认不出（config 里可开启）。
- 如果这里还是空的，先停下来问，不要猜。

## 范围
- 主线：《Les Loustics 2》各单元主题（原创题，不复制教材）。
- 扩展：同级别少儿法语常见主题，难度对标 DELF Prim A1–A1+：
  问候与自我介绍、数字 0–100、颜色、身体、家庭、动物、食物与餐点、衣服、天气与季节、星期/月份/日期、时间、学校与文具、房间与家、城市与方向、爱好与运动、节日（Noël、Pâques、anniversaire）、法国与卢森堡小常识。
- 词汇控制：以 A1 高频词为主；每题新词 ≤ 1 个，并给中文提示。

## 数量
- 静态题 ≥ 600 道；每个 skill ≥ 60 道；每个主题 ≥ 25 道。
- 数学/逻辑题合计 ≤ 10%。
- **分 4 批提交，每批约 150 道**，每批都跑 validate、贴统计表，再做下一批。

## 参数化出题器（保证每天有新题）
以当天日期为种子生成，至少做这 5 种：
1. 钟表时间（看钟写时间 / 听时间选钟）
2. 数字读写（听数字写阿拉伯数字，0–100）
3. 价格计算（€，简单加减）
4. 颜色＋名词的性数配合（un crayon vert → une gomme verte → des …）
5. 日期与星期（aujourd'hui / demain / hier）
生成器的题也要过 validate 的规则（运行时校验）。

## 质量检查
- 新增 `scripts/lint-french`：检查常见错误（标点前空格、un/une 与名词性别、形容词配合等），列出可疑题。
- 每批随机抽 20 道，把法语原文和中文解析列在回复里，供家长抽查。

## 验收
- [ ] 静态题 ≥ 600，各 skill ≥ 60，各主题 ≥ 25（贴统计表）
- [ ] 5 种生成器可用，连续 7 天模拟每天都有新题
- [ ] 连续 20 天模拟：同一道静态题（复习题除外）间隔 ≥ 14 天才再出现
- [ ] lint-french 无报错，可疑项已处理或说明
