# 阶段 1：工程骨架＋排句交互＋每日 30 题

仓库：aaronshi918-lgtm/jiaqi-french　分支：main　先读 AGENTS.md。

## 1. 工程骨架
- `package.json`，脚本：`build`、`validate`、`test`。
- `scripts/build`：把 `src/` 和 `questions/*.json` 内联成 `dist/jiaqi_french.html`（单文件，无外部依赖）。
- `scripts/validate` 检查：
  - id 全局唯一；必填字段齐全；choice/multi 的答案在选项里；order 的答案词与词块一致；
  - `skill`、`type`、`theme`、`unit` 取值在白名单内；
  - 法语字段不含中文；中文解析字段不为空；
  - 输出统计表：按 skill / type / theme / unit 计数。
- 测试用 Playwright（无头 Chromium + WebKit）。

## 2. 迁移旧题库
- 从 `legacy/jiaqi_daily_french_30.html` 的 `DB.questions` 中取出 85 题，转成新字段格式，放进 `questions/`。
- 新字段：`id, unit, theme, skill, type, level(1-3), prompt, audio_text, choices, answer 或 answers, aliases, hint_zh, explanation_zh, scene`。
- 旧题 id 保持不变（学习记录要靠它对应）。
- 旧题里的纯数学计算题统一标 `skill: "logic"`。

## 3. 排句子交互（重写）
- 点下方词块 → 移到上方答案行末尾；点答案行里的词 → 退回词池原位置。
- 只更新本题局部 DOM：**不重绘整页、不滚动页面**。
- 保留“清空”按钮；词块触控区域 ≥ 44px，iPad 上好点。
- 判分忽略大小写、标点、多余空格；支持多个正确语序（`answers` 为数组的数组）。

## 4. 每日 30 题抽题器
- 按 README 的配比抽题，配比放在 `src/config.js`。
- 以当天日期（卢森堡时区）为种子，同一天刷新页面题目不变，进度可续做。
- 复习题优先、计入名额、上限 10 道。

- [ ] `npm run validate` 通过，统计表贴在回复里

- [ ] Playwright：每日正好 30 题，配比符合 config（无听力/口语时按规则补足）
- [ ] 同一天刷新，题目和进度不变
