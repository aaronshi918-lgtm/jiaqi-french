# 阶段 2：听力＋口语

仓库：aaronshi918-lgtm/jiaqi-french　分支：main　先读 AGENTS.md。

## 音频来源（重要决定）
- **默认用设备自带的法语语音**（`speechSynthesis`，lang `fr-FR`）。iPad 上优先选 Amélie / Thomas 等系统法语声音，按名称排序选质量最好的；设置页可让家长手动选声音。
- **预留真人录音接口**：题目若有 `audio_src` 字段（`audio/` 目录里的 mp3），优先播放真人录音，没有才用设备语音。build 时把 mp3 以 base64 内联。
- 不要因为暂时没有真人录音而删除或推迟听力题。不要从网上下载来源或授权不明的音频。

## 听力
- 每道听力题有“播放”和“慢速”（rate 0.75）两个按钮，可反复听；自动播放一次。
- 题型（每种先做 ≥ 10 道示例题，大规模扩充在阶段 3）：
  1. 听音选图/emoji
  2. 听句子选意思
  3. 听数字或时间，写答案
  4. 听写单词（大小写和标点忽略；重音写错算对，但提示正确写法）
  5. 听短对话（2–4 句，可用两种声音）回答问题
- 设备没有法语声音时：顶部提示一次，该题改为显示法语文字作答，不算错。

## 口语
- 用 `SpeechRecognition` / `webkitSpeechRecognition`，lang `fr-FR`。
- 题型：看图说词、跟读句子、回答简单问题（Comment tu t'appelles ? / Quelle heure est-il ? / Tu as quel âge ?）。
- 判分宽松：去重音、去标点、冠词差异可接受；`keywords` 数组命中即算对。识别出的文字显示给孩子看。
- 先播放标准读音，再让孩子说。
- **降级**：浏览器不支持、没网、或麦克风被拒绝时 → “跟读＋录音回放（MediaRecorder）＋家长点 ✓/✗”，绝不能卡住。
- 识别失败最多重试 3 次，之后可跳过，不计错。
