## 每日 30 题配比（写进 src/config.js，可调）
| 技能 | 题数 |
|---|---|
| 听力 listening | 7 |
| 口语 speaking | 5 |
| 词汇 vocab（看图、配对） | 5 |
| 语法/改错 grammar | 4 |
| 阅读 reading | 4 |
| 排句子 order | 3 |
| 趣味逻辑 logic | 2 |

- 到期复习题计入所属技能的名额，每日复习最多 10 道。
- 某技能题不够时，按 词汇 → 阅读 → 语法 的顺序补足，并在首页提示。
- 同一技能不连续 3 道；同一主题不连续超过 2 道。
- 阶段 2 完成前没有听力/口语题，这 12 个名额临时用其他技能补足。
