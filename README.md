# 佳琪每日法语练习

阶段 1：每天 30 道原创法语练习，面向 iPad Safari 和电脑 Chrome。构建产物为可离线使用的单文件 [dist/jiaqi_french.html](dist/jiaqi_french.html)。不需要账号、后台或运行时网络请求。

## 开发与验证

使用 Node.js 20 或以上版本：

```sh
npm ci
npx playwright install chromium webkit
npm run validate
npm run build
npm test
```

`npm test` 执行 Node 单元测试，以及无头 Chromium、WebKit 的浏览器测试；浏览器测试启动前会自动重新构建。已安装系统 Chromium 时自动使用 `/usr/bin/chromium`，否则使用 Playwright Chromium。两套浏览器执行相同的 6 项 HTTP 场景，`file://` 离线验收单独由 WebKit 执行。浏览器串行运行；包含完整 30 题操作的场景限时 90 秒。

Linux 需要安装 WebKit 运行库；有管理员权限时可执行 `npx playwright install-deps webkit`。当前云实例无系统安装权限，已从签名验证的 Debian 源下载运行库并部署到用户目录中的 WebKit 运行时。配置显式使用已安装的 WebKit 可执行文件，兼容系统或用户目录运行库；所有测试均实际启动浏览器并执行断言。

校验器拒绝重复 ID、缺失字段、非法枚举、选项和答案不一致、排句缺词/重复词、法语字段含中文及缺失中文解析，并打印技能、题型、主题和单元统计。任何校验错误都会阻止构建。

开发时运行 `node scripts/serve.js`，然后在本机浏览器访问端口 4173。日常使用直接打开构建产物即可；分发时只需这个 HTML，不需携带题库和源码。

## 文件组织

- `src/config.js`：每日题数、七类技能配比、复习上限、补题顺序、连续限制、时区和字段白名单。
- `src/engine.js`：可独立测试的抽题、排序及判分逻辑。
- `src/app.js`、`src/scenes.js`、`src/styles.css`、`src/index.html`：交互、离线图示、样式和页面模板。
- `questions/*.json`：按 time / classroom / people / languages / school 分文件的 85 道旧题迁移结果；保留原始 ID，全部标记为原题库的第 1 单元。旧版纯计算题标记为 logic。`audio_text` 暂留空，听说内容留待阶段 2。
- `scripts/`：题库读取、校验、单文件构建和本地静态服务。
- `tests/`：迁移一致性、365 天抽题、复习上限、补题、校验负例和双浏览器交互测试。
- `legacy/`：旧版仅供参考，不修改。

## 每日计划和记录兼容

日期使用卢森堡时区，同日计划和作答草稿存入浏览器本地存储，刷新可续做。答题跨越午夜时，已开始的答题仍记入原日期；返回首页后生成新一天的计划。

默认配置为听力 7、口语 5、词汇 5、语法 4、阅读 4、排句 3、逻辑 2。阶段 1 缺少听说题，按词汇 → 阅读 → 语法顺序补足，因此无历史记录时为词汇 17、语法 4、阅读 4、排句 3、逻辑 2。到期复习优先占用其所属技能名额，每日最多 10 道；所有新生成计划均不连续出现 3 道同技能或同主题。

继续读取 `jiaqi-french-daily-v1`，保留旧卡片、历史作答和题目 ID，已开始的旧版 40 题计划继续完成。这里没有提前做阶段 4 的 version 2 迁移。旧版和新版文件路径不同可能属于不同的浏览器存储空间；换文件或设备前应在旧版导出 JSON，在新版“备份与恢复学习记录”中导入，不会自动跨文件或跨设备读取。

排句词池位置固定，点词后词池按钮禁用，答案区新增词块；点已选词会在原池位置恢复。仅更新本题答案区，不重绘题目或页面。支持撤销、清空、重复词和多个正确语序。

## 本次验证与已知限制

- `npm run validate && npm run build && npm test` 整体通过：8 项 Node 测试、13 项浏览器测试（Chromium 6、WebKit 7），失败 0、跳过 0。覆盖完整 30 题、连点 6 词不滚动、44px 触控目标、草稿恢复、旧记录和时区边界。
- Chromium 的 `file://` 管理策略保持原样，离线打开改由 WebKit 验证：加载前拦截 HTTP(S) 并确认零外部请求，文件刷新保持计划，再切换离线状态验证答题。WebKit 在离线模拟下会拒绝初始 `file://` 导航，因此不在导航前调用 `setOffline(true)`。
- iPad Safari 的真实触控、文件打开及设备行为仍需手工验收。
- 85 题中若非到期题数量不足以和最多 10 道复习题组成 30 题，首页明确提示、保留旧记录并暂停生成新计划；不会偷偷增加复习上限或重复凑题。后续扩充题库可缓解此情况。
